# Changelog

## v1.2 - 2026-09-10

- Fixed Windows PowerShell parsing failure caused by Unicode smart quotes.
- Added a self-contained single-file CMD launcher.
- Added persistent crash logging to `%TEMP%\NCM_Batch_Converter_error.log`.
- Added a diagnostics launcher for PowerShell/parser checks.
- Retained batch conversion, recursive scanning, directory preservation, overwrite control, and optional source deletion.

## v1.1

- Improved startup diagnostics and error visibility.
- Added single-file launcher packaging.

## v1.0

- Initial Windows GUI batch converter.
- Local NCM decryption with automatic source-format detection.
